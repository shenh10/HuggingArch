# Independent B300 kernel calibration

[calibration_rows.json](calibration_rows.json) contains the nine validated
training rows consumed by the estimate's explicit `envelope` selector.
[Indexer's summary](indexer/summary.json) and [projection summary](gemm/summary.json)
retain shapes, training/holdout timings, actual seeds, lookup results and scope.
[Runtime provenance](indexer/runtime.json) records package versions and source
hashes. Independent seeds test same-shape repeatability, not unseen-shape or
whole-model accuracy.

The raw CSVs, per-job plans, environment dumps and test logs are externalized
under `/tmp/scratch-space/k3-performance/benchmark/pr-review-raw-evidence/`
in `kimi-k31-b300-calibration/{indexer,gemm}/`. Identical originals remain in
`/tmp/scratch-space/k3-performance/benchmark/{indexer,gemm}-calibration/`.
The archive manifest records their checksums. Summary lookup checks were run
against those CSVs before externalization.

## Reproduce into a fresh persistent directory

These commands need the recorded SGLang environment and an idle B300. They
copy the retained scripts into a fresh output directory, so generated raw
files do not repopulate this Git checkout. Run from the HuggingArch root:

```bash
source /tmp/scratch-space/k3-performance/env.sh
repro_root=$(mktemp -d /tmp/scratch-space/k3-performance/benchmark/calibration-repro.XXXXXX)
mkdir -p "$repro_root/indexer" "$repro_root/gemm"
cp docs/evidence/kimi-k31-b300-calibration/indexer/{run.py,summarize.py} "$repro_root/indexer/"
cp docs/evidence/kimi-k31-b300-calibration/gemm/{plan.py,run.py,summarize.py} "$repro_root/gemm/"
# GEMM run.py consumes all-jobs.json, generated by this required CPU step.
CUDA_VISIBLE_DEVICES='' PYTHONPATH="$PWD" /opt/sglang/bin/python "$repro_root/gemm/plan.py"
for group in indexer gemm; do
  CUDA_VISIBLE_DEVICES=7 PYTHONPATH="$PWD" /opt/sglang/bin/python "$repro_root/$group/run.py" train
  CUDA_VISIBLE_DEVICES=7 PYTHONPATH="$PWD" /opt/sglang/bin/python "$repro_root/$group/run.py" holdout
  CUDA_VISIBLE_DEVICES='' PYTHONPATH="$PWD" /opt/sglang/bin/python "$repro_root/$group/summarize.py"
done
```

Indexer `run.py` generates its six physical-key jobs when no saved plan exists.
GEMM `plan.py` generates the full plan before `run.py` selects the three audited
projection shapes. Existing archived jobs and CSVs are evidence of the original
measurement, not prerequisites for a new run. The scripts are retained unchanged.
